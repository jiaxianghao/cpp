# 学习方法与 C++ 热身

## 一道题的完整路径

先用一句话定义输入与输出，再给一个手算例子。写最直接的暴力解；用数据规模判断瓶颈。然后选择结构，写清“循环每一轮开始时哪些事实成立”。实现后先测边界，再用暴力结果对照；最后脱离代码讲解。

不要把“读懂”当作“能写”。遇到参考程序，先预测输出，再运行；合上程序后，只凭不变量重写最核心的十几行。隔天重新做一次，比当天连看三遍更能暴露遗忘。

## C++ 最低准备

- `std::vector<T>`：连续存储；`size()` 是无符号类型。倒序循环需要特别注意，不能写 `size_t i >= 0`。
- `const std::vector<int>&`：避免复制且不修改输入；`std::vector<int> a` 按值传参会复制调用方左值。
- `std::string` 在本项目按字节处理；UTF-8 中文不是一字节一个字符。
- `std::sort` 默认升序；比较器必须是严格弱序，不能用 `<=`。
- `std::lower_bound` 返回迭代器；只有随机访问迭代器才能直接减法求下标。二分比较次数与迭代器移动次数不是同一回事。
- `std::unordered_map` 的 `operator[]` 在键不存在时会插入默认值；仅查询使用 `find`。
- `std::priority_queue<int>` 默认最大堆；最小堆写 `priority_queue<int, vector<int>, greater<int>>`。
- `long long` 适合本项目的累计和，但并不代表永不溢出；推导数据范围后再选类型。`1LL * a * b` 可避免先做 int 乘法溢出。
- `unique_ptr` 表示唯一所有权；树节点随根释放。链表示例使用栈上节点，只修改链接，不负责释放；不要对它们执行 `delete`。
- 容器扩容可能使迭代器、指针和引用失效；不要保存 vector 元素地址后又无条件 `push_back`。

若这些内容陌生，先用 2–3 个学习日写“小数组统计、字符串遍历、函数传参”三个小程序，再开始主线。

## 正确性证明的三个入口

**循环不变量**：二分中 `[0,left)` 都小于 target，`[right,n)` 都大于等于 target。初始为空所以成立；每次更新保持成立；退出时区间为空，答案是 left。

**递归归纳**：先假设左右子树函数返回正确高度，再组合 `1 + max(left,right)`；空树返回 0，递归必须不断缩小。

**交换论证**：区间调度选最早结束者。任意最优解的第一个区间都可换成它，且不会减少后续可选空间，因此存在包含该选择的最优解。

证明从具体不变量开始，不需要堆术语。随机测试和暴力对照能发现错误，但不是一般性正确性证明。

## 调试顺序

1. 固定一个最小失败输入，不先改十处代码。
2. 写出预期结果，确认题意和边界约定。
3. 打印每轮 `left/right/mid`、队列或 DP 状态，找第一处与手算不同的位置。
4. 修正原因，保留失败输入作为回归检查。
5. 再运行原有检查，确认没有破坏其他行为。

每个示例把检查放在 `main()` 中，`tests/check.hpp` 负责失败时抛出异常。这样即便使用 Release 构建，检查也不会像 `assert` 那样被关闭。

## 复杂度怎么写

区分输入存储、额外空间、递归栈和输出空间。例如排列：递归和路径 O(n)，但保存全部答案要 O(n·n!)；“空间 O(n)”只有在不计输出时才成立。两个连续 O(n) 循环相加是 O(n)，嵌套循环也要看总迭代次数。

图算法明确 V 是顶点数、E 是边数；无向图邻接表通常保存 2E 条邻接项。哈希平均 O(1) 不等于最坏 O(1)，vector 尾插摊还 O(1) 不等于每次都 O(1)。
