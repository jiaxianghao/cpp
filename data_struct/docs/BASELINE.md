# 起点自测：30 分钟

不查资料；不会就标记。目的不是分数，而是找到“概念忘了”还是“知道但写不出”。

## 前 10 分钟：概念

每题用一两句话回答。

1. 数组随机访问与链表按序号访问的复杂度分别是什么？链表插入什么时候才是 O(1)？
2. 两层循环一定是 O(n²) 吗？举一个不是的例子。
3. 二分查找依赖什么性质？对有重复元素的数组，怎么定义返回值？
4. 普通 BST 的查找为什么不一定是 O(log n)？
5. BFS 为什么能求无权图最短路径？什么时候不能直接用？
6. 贪心与动态规划的核心区别是什么？

## 中间 15 分钟：动手

在纸上或临时文件中完成；不必搭建工程。

- A：写一个函数，返回非递减数组中第一个大于等于 x 的下标；不存在返回长度。用 `[]`、`[2,2]`、`[1,3]` 测试。
- B：画图反转 `1 -> 2 -> 3 -> null`，每步写出 `previous/current/next`。
- C：写出“到第 n 级台阶，每次走 1 或 2 级”的状态含义、递推式和 n=0、1 的边界。约定不走也是一种走法。

## 最后 5 分钟：记录

给每题标记：能独立完成 / 有印象但不完整 / 不会。把最不确定的三项填到 [进度表](PROGRESS.md)。

- 概念大多忘了：按顺序学习，不额外加题。
- 概念清楚但写不出：每天 20 分钟主要用于手写和调试。
- 能写但边界错误多：每题先列空、单元素、重复、极端顺序四类输入。
- 全部顺畅：仍做每模块必做题；连续两个模块闭卷验收通过，可压缩已熟悉的阅读日。

参考答案在 [答案页](SOLUTIONS.md#起点自测)，完成后再核对。
