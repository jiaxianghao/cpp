# 分层提示与参考思路

先完成起点自测或对应练习。第一层只看“提示”，仍卡住再看“参考过程”。这些是解题方向；函数签名与输入边界以练习模板为准。

## 起点自测

1. 数组随机访问 O(1)，链表按序号访问 O(n)；已知合适节点/前驱后，链接操作才 O(1)。
2. 不一定。两个单向指针都最多前进 n 次，即使 while 嵌套，总 O(n)。
3. 需要有序或单调判定；必须定义是任意匹配、第一个 ≥、还是第一个 >。
4. BST 可能退化为链，高度 n；复杂度本质是 O(h)。
5. 队列按层扩展，首次发现对应最少边数；不同边权时最少边数不等于最小权和。
6. 贪心需证明局部选择可以保留全局最优；DP 描述子问题并合并候选结果，复用重复状态。

动手 A：维护 `[l,r)` 未知区间；a[mid]<x 则 l=mid+1，否则 r=mid；返回 l。B：每轮先保存 next，再反转链接，最后移动 previous/current。C：f[0]=1、f[1]=1、f[n]=f[n−1]+f[n−2]。

## 01

提示：为每个查询单独扫描会重复哪些加法？

参考过程：创建 n+1 长度的 long long 数组 p，p[0]=0；循环 p[i+1]=p[i]+a[i]。对每个 (l,r) 追加 p[r]−p[l]。构建 O(n)，q 次查询 O(q)。空数组也有 p[0]。

B 差分：长度 n+1 的 d 初始 0；每次 d[l]+=delta、d[r]−=delta；最后前 n 项前缀累加。C 最大子数组：ending=max(x,ending+x)，best=max(best,ending)；从第一个值初始化，避免全负出错。

## 02

提示：已经保留的元素全在数组前缀，当前元素应该与谁比较？

参考过程：write=0；逐个读 x，如果 write==0 或 a[write−1]!=x，则 a[write++]=x；返回 write。写入位置不会超过读位置，因此不会覆盖尚未读取的元素。时间 O(n)、额外空间 O(1)。

B 反转：prev=null，保存 next、改链接、移动指针，结束返回 prev。C 单调栈：存下标；新值严格大于栈顶时弹出 idx，答案为 i−idx；其余默认 0。相等不能弹出。

## 03

提示：遇到重复字符时，旧出现位置可能已经不在当前窗口。

参考过程：left=best=0，last 表为空。扫描 right，若找到旧位置，left=max(left,last[c]+1)；更新 last[c]=right；best=max(best,right−left+1)。平均 O(n)。字节表也可用 256 项数组，索引应转换为 unsigned char。

B 子数组计数：count[0]=1；每次先累加前缀 p，答案加 count[p−k]，再 count[p]++。C 正数最短窗口：右端扩展加和；while sum≥target 时更新最短并移除左端。正数保证缩窗时总和单调不增。

## 04

提示：“第一个 > target” 左边所有值应满足什么？

参考过程：left=0，right=n；a[mid]≤target 则 left=mid+1，否则 right=mid。退出返回 left。区别于 lower_bound 的地方是 `<` 改成 `<=`；区间约定保持不变。

B 次数：upper_bound−lower_bound。C 运输容量：二分 `[max(weight),sum(weight)]`；给定容量顺序装货，装不下当前件时开新的一天。所需天数≤D 为可行。容量越大，最少所需天数不增加，二分第一个可行值；累计量使用宽整数。

## 05

提示：如果知道左右子树高度，整棵树高度还缺什么？

参考过程：root 为 null 返回 0，否则返回 1+max(height(left),height(right))。每节点访问一次 O(n)，栈深度 O(h)。

B 迭代中序：current 非空就不断压栈并走左；否则弹栈访问，current 转右；循环条件为 current 非空或栈非空。C BST 检查：递归传递允许的开区间上下界，或者中序遍历时比较当前值与前一个值是否严格递增；用“是否存在前值”的状态处理 INT_MIN，而不是把 INT_MIN 当作无穷小。

## 06

提示：合并两个集合时，应该修改任意元素还是代表元？

参考过程：parent[i]=i、size[i]=1。find(x)：若 parent[x]!=x，就令 parent[x]=find(parent[x])；返回 parent[x]。unite：找到两根，相同返回 false；按 size 小挂大，更新根大小，返回 true。初始化 O(n)，每操作摊还 O(α(n))。

B Top K：最小堆，每个值 push 后若 size>k 则 pop；最终逐次 pop 为升序。C 分量数：初始 n，只有 unite 返回 true 时减一，重复边和自环不会减。

## 07

提示：同一顶点能被多个前驱发现，何时设置已访问标志？

参考过程：distance 全部 −1，源点为 0 并入队；弹出 u，遍历邻居 v，若 distance[v]==−1，立即设为 distance[u]+1 并入队。邻接表时间 O(V+E)，额外空间 O(V)。

B 恢复路径：发现 v 时 parent[v]=u；若目标不可达直接返回无路径，否则从终点追溯到源点再 reverse，源点到自身为单节点路径。C 拓扑：统计入度、入度 0 入队、删除出边；处理数是否等于 V 决定有无环，不能用结果是否为空判断。

## 08

提示：选一条边时，如何快速判断会不会造成环？

参考过程：按权重升序排序，初始化 DSU(n)、total=0、components=n。每条 (u,v,w)，仅当 unite(u,v) 为 true，total+=w、components--。负边照常排序；自环的两端始终同组；多重边中较重的重复连接不会再被接纳。n=0 返回 `{0,0}`。

B Dijkstra：成功松弛时修改 parent，堆项过期时跳过；不可在第一次入堆就认定最终距离。C Bellman–Ford：V−1 轮松弛，仅从有限距离点出发；再检测一轮能否改进。不可达负环不会被触发。完整接口需区分有限距离、不可达和受负环影响的距离。

## 09

提示：对子集问题，每一层是否只需决定一个元素要不要选？

参考过程：dfs(i)，当 i==n 时复制 path 到结果；否则先 dfs(i+1) 表示不选，再 push(a[i])、dfs(i+1)、pop。初始 dfs(0)。空输入直接保存空 path，所以结果不是空列表，而是包含一个空列表。

B 排列：排序，used 标记，下标 i 已用就跳过；若与前一个值相同且前一个未用，同层跳过；选择后递归再撤销。C 组合：传 start，循环选 i 后递归 i+1；path.size()==k 时收集；若 n−start+1 小于仍需个数就结束该分支。

## 10

提示：输入排序后，新区间只需要与结果中的哪一段比较？

参考过程：按起点升序。结果为空或新段 l>最后一段 r，则追加；否则最后一段 r=max(旧r,新r)。闭区间接触也合并，所以是 `l>r` 才分开。包含关系无需单独分支。

B 区间调度：按结束升序，用 start≥last_end 判断兼容；交换最优解首段为最早结束段，后续不受影响。C 反例：最短时长优先在 `[0,3),[3,6),[2,4)` 上只选 1 段，最优为 2；硬币 `[1,3,4]` 凑 6 最大优先得到 3 枚，最优 2 枚。前者改结束时间贪心，后者一般需 DP。

## 11

提示：最后选一枚 c，剩下的是哪个更小金额的同类问题？

参考过程：dp 长度 amount+1，初始化不可达值（在练习的小规模下可用 amount+1），dp[0]=0。对 a=1..amount，遍历 c≤a 且 dp[a−c] 可达的硬币，dp[a]=min(dp[a],dp[a−c]+1)。结束不可达返回 −1。硬币为正，所以不会依赖当前或更大的金额。

B 0/1 背包：二维从上一行取值；一维容量倒序，避免同件重复。C LCS：相等取左上+1，否则上/左最大。`ab` 对 `acb` 的完整表（含空前缀）：

| | 空 | a | c | b |
|---|---|---|---|---|
| 空 | 0 | 0 | 0 | 0 |
| a | 0 | 1 | 1 | 1 |
| b | 0 | 1 | 1 | 2 |

## 12

提示：失配前已经匹配的那一段，有哪些后缀仍可能成为模式的前缀？

参考过程：先构造 pi。每个 i 从 pi[i−1] 开始，失配反复 j=pi[j−1]，匹配则 j++，保存 pi[i]。扫描文本时同样维护 j，达到模式长度返回 i+1−m。空模式在任何索引访问之前返回 0；扫描结束返回 npos。

B Fenwick：外部 index 先加 1；更新 i+=lowbit(i)，查询 i-=lowbit(i)。按 [0,r) 查询时直接从内部 r 开始。C 所有匹配：匹配成功后记录起点，再令 j=pi[m−1] 继续，不清零，否则可能漏掉重叠。
