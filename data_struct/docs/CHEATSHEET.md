# 复杂度与选型速查

这张表用于复习后的检索，不代替推导。n 为元素数，V/E 为顶点/边数，h 为树高，k 为堆保留元素数。

## 结构

| 结构 | 常用操作 | 时间 | 什么时候选 / 注意点 |
|---|---|---|---|
| 数组/vector | 下标访问、尾插、中间插删 | O(1)、摊还 O(1)、O(n) | 连续数据、随机访问；扩容使引用失效 |
| 单链表 | 按序号访问、已知前驱插删 | O(n)、O(1) | 频繁局部链接操作；额外指针和缓存成本 |
| 栈/队列/deque | 端点操作 | 常见实现 O(1) 或摊还 O(1) | 后进先出/先进先出/两端访问 |
| 哈希表 | 查找、插删 | 平均 O(1)，最坏 O(n) | 键查询、计数；不提供有序性 |
| 平衡搜索树 | 查找、插删 | O(log n) | 有序键、范围边界 |
| 普通 BST | 查找、插删 | O(h)，最坏 O(n) | 理解树搜索，不保证平衡 |
| 二叉堆 | 读顶、插入、删顶 | O(1)、O(log n)、O(log n) | 优先级、Top K；不是任意键查找结构 |
| 并查集 | 合并、找代表元 | 按大小+压缩摊还 O(α(n)) | 动态加边的连通性；不恢复路径 |
| 前缀和 | 构建、区间和 | O(n)、O(1) | 静态数组 |
| Fenwick | 单点加、前缀和 | O(log n) | 动态区间和；下标约定重要 |
| 线段树 | 单点更新、区间聚合 | 通常 O(log n) | 可合并信息，区间操作需额外设计 |

## 问题到方法

| 问题特征 | 优先尝试 | 使用前问自己 |
|---|---|---|
| 找已见过的键/频次 | 哈希 | 表里存下标、次数还是状态？ |
| 有序边界、单调可行性 | 二分 | 真/假分界是否真的单调？ |
| 连续区间且左右边界单向移动 | 滑动窗口 | 移动左端的效果有无单调性？ |
| 静态连续区间求和 | 前缀和 | 是否有更新？区间是否半开？ |
| 右侧第一个更大/小 | 单调栈 | 严格还是非严格？需要值还是距离？ |
| 反复取当前最小/最大 | 堆 | 小顶还是大顶，过期项如何处理？ |
| 遍历层级、无权最短路 | BFS | 是否入队时标记？ |
| 深度探索、树递归 | DFS | 最大深度多大，状态能否重复？ |
| 任务依赖 | 拓扑排序 | 图是否有向，是否需要报告环？ |
| 非负权最短路 | Dijkstra | 不能把首次入堆当最终确定 |
| 连接所有点总成本最小 | MST | 图是否无向、连通？ |
| 要求所有可行方案 | 回溯 | 输出规模本身多大，如何撤销？ |
| 局部选择可证明安全 | 贪心 | 能写交换证明还是只有直觉？ |
| 重复子问题、状态可复用 | DP/记忆化 | 状态包含未来所需的全部信息吗？ |
| 单模式精确匹配 | KMP | 返回首次还是全部，空模式如何定义？ |

## 写代码前的十秒检查

1. 输入允许空、重复、负数吗？下标是 0-based 还是 1-based？
2. 区间是闭区间还是半开？答案“不存在”如何表达？
3. 谁拥有节点？是否会修改输入？
4. 和、乘积、计数是否超出 int？
5. 不变量、循环结束条件、递归终止条件分别是什么？

## 常见复杂度

归并 O(n log n)、二分 O(log n)、单调栈 O(n)、BFS/DFS O(V+E)、拓扑 O(V+E)、Kruskal 主要为 O(E log E)、Bellman–Ford O(VE)、Floyd O(V³)、0/1 背包 O(nC)、LCS O(nm)、KMP O(n+m)。

输出全部子集至少受 O(n·2ⁿ) 输出规模约束；排列最坏 O(n·n!)。分析空间时把输出、递归栈与额外结构分别说明。
