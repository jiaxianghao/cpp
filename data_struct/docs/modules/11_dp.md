# 11 动态规划（第 21–22 周，可延长）

先修：递归、数组、复杂度。目标：先定义状态，再写递推，最后才压缩空间。

## 1. 从重复子问题到 DP

递归求台阶走法会重复求同一个 n；记忆化把每个状态结果缓存一次。自底向上按依赖顺序填表，是另一种计算同一递推的方法。

每道 DP 先写五件事：状态含义、转移来源、边界、计算顺序、答案位置。不能只背 `dp[i]=...`。不同状态即使数组维度相同，含义也可能完全不同。

台阶例：f[i] 是恰好到第 i 级的走法数；最后一步来自 i−1 或 i−2，所以 f[i]=f[i−1]+f[i−2]；f[0]=1、f[1]=1。大 n 计数会溢出，需明确范围或按题意取模。

## 2. 0/1 背包：先二维，后压缩

定义 dp[i][c]：只看前 i 件物品，容量上限 c 内的最大总价值，可以不选。

- 不选第 i 件：dp[i−1][c]。
- 若放得下，选择：dp[i−1][c−w]+v。
- 取两者最大；dp[0][c]=0。

时间 O(nC)，二维空间 O(nC)。压成一维后必须 c 从大到小更新，确保读取的 dp[c−w] 仍属于上一轮。只有一件重 2、值 3 的物品，容量 4；若正序更新，先得到 dp[2]=3，再得到 dp[4]=6，就把同一件用了两次。

“恰好装满”是不同语义：只有 dp[0]=0，其余不可达，不能全部初始化为 0。C 是数值容量，所以 O(nC) 常称伪多项式复杂度，并非对容量的二进制位数多项式。

## 3. 完全背包与最少硬币

硬币可无限使用，金额 a 的最少枚数可由 `dp[a-c]+1` 得到。定义 dp[0]=0，其余为不可达；正面值 c 才合法。按金额从小到大，枚举所有币值，依赖的金额始终更小。

`coins=[1,3,4]`：dp[0..6] 为 `0,1,2,1,1,2,2`。金额 6 最优是两枚 3。时间 O(金额×币种数)，空间 O(金额)。求最少枚数和求方案数量不是同一题，循环次序对计数中的排列/组合尤其关键。

## 4. 最长公共子序列 LCS

子序列允许跳过元素，不要求连续。dp[i][j] 是 a 前 i 个字符与 b 前 j 个字符的 LCS 长度。

若末字符相同，取 dp[i−1][j−1]+1；不同则取 max(dp[i−1][j],dp[i][j−1])。任一字符串为空时长度 0。答案在 dp[n][m]，时间 O(nm)、示例空间 O(nm)。恢复序列需回溯转移，不仅返回长度。

例如 a=`abcde`、b=`ace`，答案为 3；最长公共**子串**要求连续，状态和转移不同，不能沿用同一个公式。
