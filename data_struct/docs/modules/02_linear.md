# 02 数组、链表、栈与队列（第 3–4 周）

先修：指针基础、复杂度。目标：根据访问方式选结构，而不只记住名称。

## 1. 数组与链表

数组连续存储，按下标访问 O(1)，中间插入/删除要移动后缀，O(n)。vector 尾部 push_back 摊还 O(1)，扩容的某一次仍可能 O(n)。容量 capacity 与元素数 size 不同，reserve 不会增加元素数。

链表靠指针连接，按序号找节点 O(n)。**已知插入位置（单链表通常需前驱）**后，修改链接可 O(1)；如果先遍历寻找位置，总操作仍 O(n)。连续数组往往有较好的缓存局部性，不能因为链表删除 O(1) 就默认更快。

## 2. 反转链表的连接不变量

`previous` 指向已反转部分，`head` 指向未处理部分。每次先保存 `next=head->next`，再令 `head->next=previous`，最后移动两个边界。

| 步骤 | 已反转部分 | 未处理部分 |
|---|---|---|
| 初始 | null | 1→2→3 |
| 处理 1 | 1→null | 2→3 |
| 处理 2 | 2→1→null | 3 |
| 结束 | 3→2→1→null | null |

不先保存 next，就会丢失未处理链。时间 O(n)、额外空间 O(1)。示例节点由调用方持有，不在反转函数里分配/释放。

快慢指针：在存在环的链中，快指针每轮相对慢指针前进一个节点，因此最终相遇；无环时快指针先到 null。找环入口时，相遇后一个指针回头，两者同速推进即可，证明留作拓展。

## 3. 栈与队列

栈是后进先出：括号匹配时栈顶是最近一个尚未配对的左括号。遇右括号要先检查空栈，再比较类型；扫描完成还要检查是否有剩余左括号。

队列先进先出：BFS 按距离层次扩展。`std::queue` 的 pop 不返回元素，需要先 front 再 pop。双端队列允许两端插入/删除，可用于滑动窗口最大值。

## 4. 单调栈为什么是 O(n)

求每个元素右侧第一个更大值。栈存尚未找到答案的下标，遇新值时弹出所有更小的栈顶并填写答案。例如 `[2,1,2,4,3]` 得 `[4,2,4,-1,-1]`。

while 看似嵌套，但每个下标只入栈一次、出栈至多一次，总 O(n)，额外空间 O(n)。严格更大时条件是 `<`，不是 `<=`。存下标便于填原位置答案，也能算距离。
