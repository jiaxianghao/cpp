# 07 图表示、遍历与拓扑排序（第 13–14 周）

先修：队列、递归。目标：把实际关系转换为顶点和边，区分有向/无向、连通/可达。

## 1. 表示方式决定存储成本

邻接矩阵用 V×V 表，空间 O(V²)，判断某条边存在可 O(1)，枚举一个顶点的邻居 O(V)。邻接表空间 O(V+E)，枚举邻居与实际度数相关，适合稀疏图。

无向边 u–v 通常保存 u→v、v→u 两项；有向边只存单向。不要把“u 可到 v”等同于“v 可到 u”。本项目顶点编号统一为 `[0,V)`，程序假定编号合法。

## 2. BFS：层次就是无权距离

源点距离为 0，入队。每次取队首 u，对尚未访问的邻居 v 赋 `distance[v]=distance[u]+1`，并入队。必须在**入队时**标记，否则多个前驱可能重复加入同一顶点。

队列先处理距离 d 的顶点，再处理 d+1，因此首次发现即最少边数。这个结论适用于无权图或等正权边图；不同权值时，边数少不代表总代价小。

示例边：0→1、0→2、1→3、2→3，另有孤立点 4。从 0 出发距离为 `[0,1,1,2,-1]`。-1 表示不可达，不是距离 0。

## 3. DFS：探索完整分支

递归 DFS：进入顶点即 visited=true，递归未访问邻居。也可用显式栈，避免很深的递归。邻接表 BFS/DFS 均为 O(V+E)，额外空间 O(V)。

如果要遍历非连通图，应在所有未访问顶点上重新启动搜索。无向图计连通分量可这样做；有向图中这不等于强连通分量。

无向图 DFS 判环要跳过父边；有向图判环需区分“当前递归路径中”和“已经完全处理”的点，常用三色状态。单一 visited 不足以区分回边与指向已完成节点的边。

## 4. 拓扑排序：依赖先于任务

只对有向无环图 DAG 存在完整拓扑序。Kahn 方法：计算入度，把所有入度 0 的点入队；取出 u 放入结果，删除其出边（邻居入度减一），新入度 0 的点入队。

不变量：当前队列中的点已没有未处理前驱。若最后处理数少于 V，剩余部分含环。拓扑序可能不唯一，因此测试应验证“每条边 u→v 中 u 在 v 前面”，而不是只比较某个固定序列。

时间 O(V+E)，空间 O(V)。空图的空序列是合法结果，不能只用结果是否为空判断有环；示例单独返回 acyclic 标志。
