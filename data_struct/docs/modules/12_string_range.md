# 12 字符串匹配、区间结构与综合复习（第 23–24 周）

先修：前缀和、数组、循环不变量。目标：手写 KMP，能推演 Fenwick；后者可在综合阶段继续练。

## 1. 朴素匹配的重复工作

文本长 n，模式长 m；每个起点逐字符比较，最坏 O(nm)。当长串前缀重复时，失败后重新从模式开头比较会重复已知信息。KMP 利用模式本身的前后缀关系避免文本指针回退。

本项目以字节为单位，和 std::string::find 的索引语义一致；空模式首次匹配位置为 0，找不到返回 std::string::npos。

## 2. 前缀函数 pi

pi[i] 是 pattern[0..i] 的最长相等**真前缀与后缀**长度，真前缀不包含整串本身。例如 `ababaca` 的 pi 为 `[0,0,1,2,3,0,1]`。

处理 i 时从 j=pi[i−1] 开始。若 pattern[i] 与 pattern[j] 不同，退到 j=pi[j−1]，尝试更短的已知边界；匹配则 j++。不是简单 j--，因为只有这些边界长度保持前后缀关系。

搜索文本时 j 表示已匹配的模式前缀长度；失败同样沿 pi 回退，成功 j++；达到 m 即发现完整匹配。

虽然有 while，j 的增加总次数受扫描长度限制，回退总量也受增加量限制，因此预处理 O(m)、搜索 O(n)，额外空间 O(m)。示例返回首次匹配；若寻找所有重叠匹配，记录后需退到 pi[m−1] 继续。

## 3. 动态区间求和：Fenwick 树

静态数组用前缀和很简单，但单点修改代价 O(n)。Fenwick 支持单点增量更新和前缀求和，各 O(log n)、存储 O(n)。

内部下标从 1 开始，`lowbit(i)=i & -i`（本例 i 为正整数）。bit[i] 存内部区间 `(i-lowbit(i), i]` 的和。例如 bit[6] 覆盖 5、6，bit[4] 覆盖 1..4。

查询前 6 项：取 bit[6]，再取 bit[4]，到 0 结束；每次 `i -= lowbit(i)`。更新内部位置 3：依次影响 3、4、8…，每次 `i += lowbit(i)`。

对外示例用 0-based：`add(index,delta)`，`sum(end)` 返回 `[0,end)`；区间和为 sum(r)−sum(l)。输入需满足 index 在 `[0,n)`、end 在 `[0,n]`。不要向内部更新循环传入 0，否则 lowbit(0)=0 无法前进。

## 4. 选型与综合

| 需求 | 优先考虑 |
|---|---|
| 静态区间和 | 前缀和 |
| 单点加、区间和 | Fenwick |
| 单点修改、区间最小值等可合并信息 | 线段树 |
| 区间批量加、最后一次还原全部值 | 差分数组 |
| 静态区间最小值、大量查询 | Sparse Table 等选学结构 |

线段树把区间二分，每节点存可合并信息；单点更新和区间查询常为 O(log n)，空间 O(n)。懒标记解决某些区间更新，需设计标记如何合并，见进阶地图。
