# 04 排序、二分与分治（第 7–8 周）

先修：复杂度、递归。目标：能手写归并和边界二分，了解其他排序的取舍。

## 1. 排序不是只有快慢

| 算法 | 时间 | 额外空间 | 通常实现的稳定性 |
|---|---|---|---|
| 插入排序 | 最好 O(n)，最坏 O(n²) | O(1) | 稳定 |
| 冒泡（有提前结束） | 最好 O(n)，最坏 O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | 数组版 O(n) | 可稳定 |
| 快速排序 | 平均 O(n log n)，最坏 O(n²) | 平均栈 O(log n)，最坏 O(n) | 通常不稳定 |
| 堆排序 | O(n log n) | O(1) | 不稳定 |

稳定指相等键元素的原有相对次序不变，例如先按姓名排序，再稳定地按部门排序。`std::sort` 不保证稳定；需要时使用 `std::stable_sort`。比较排序一般情形有 Ω(n log n) 下界，计数/基数排序靠限制键类型与范围避开比较模型。

## 2. 归并：先各自有序，再合并

把 `[left,right)` 切成两个较小区间，递归排序后，用两个指针选择较小者写入辅助数组。相等时先取左侧，保持稳定。退出条件是长度不超过 1。

`[4,1,3,2] → [4,1]+[3,2] → [1,4]+[2,3] → [1,2,3,4]`。每层合并总计 O(n)，层数 O(log n)。示例只分配一次长度 n 的辅助数组；加递归栈后总额外空间仍为 O(n)。

快速排序采用划分后递归，关键是选定一种区间/分区约定。已排序数组配首元素作 pivot 会退化；随机化可改善期望性能，但不能消除理论最坏情况。第一轮不要求手写多套 partition。

## 3. 用不变量写二分

目标是“第一个 >= x”，而不是含糊的“查找 x”。保持 `[0,left)` 全部 < x，`[right,n)` 全部 >= x，未知部分为 `[left,right)`。

`mid=left+(right-left)/2`。若 `a[mid]<x`，mid 不可能是答案，令 left=mid+1；否则答案不会在 mid 右侧，令 right=mid。退出 left=right 即分界，可等于 n。

例如 `[1,2,2,4]` 找 2：`[0,4) → [0,2) → [0,1) → [1,1)`，结果 1。空数组初始即结束。

## 4. 答案二分

不一定对数组二分，也可对具有单调性的可行性判定二分。例：用不超过 D 天运完按顺序排列的正重量货物；容量增加不会使可行方案变不可行。下界 max(weight)，上界 sum(weight)，判定函数贪心统计天数。

先证明判定单调，再选择“第一个可行值”的边界。若判定一次 O(n)，容量范围 R，整体 O(n log R)。不单调的条件不能直接二分。
