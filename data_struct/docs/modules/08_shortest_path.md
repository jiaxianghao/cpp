# 08 最短路与最小生成树（第 15–16 周）

先修：图遍历、堆、并查集。目标：分清优化目标，并按边权条件选择算法。

## 1. 松弛是什么

已知到 u 的候选距离 d[u]，边 u→v 权重 w 给出另一条到 v 的路线。若 `d[u]+w < d[v]`，就更新 d[v]。这叫松弛。源点 d[s]=0，其他为 INF；不可达点不能参与 INF+w 运算。

需要恢复路径时，更新距离同时记录 parent[v]=u，终点逆向跟踪即可。若只求距离，不必提前增加路径结构。

## 2. Dijkstra 的适用条件与堆实现

所有边权必须非负。每轮选择当前候选距离最小的点 u；非负边保证绕到其他未确定点再回来，不可能得到比当前更小的 u 距离。这个性质支撑贪心选择。

示例：0→1(10)、0→2(1)、2→1(2)、1→3(1)、2→3(8)。先得到 d[1]=10，处理 2 后改为 3，最终 d[3]=4。

priority_queue 不直接支持降低某项键值，所以每次改进插入新项；旧的 `(10,1)` 仍在堆中，取出时通过 `d != distance[u]` 跳过。不能在首次入堆时永久标记完成。

本实现使用懒删除，堆可保存 O(E) 项。一般写 O((V+E) log(E+2)) 时间、O(V+E) 额外空间；简单图常简写成 O((V+E) log V)。不要把实现的堆空间误写成始终 O(V)。

## 3. 边权条件改变时

| 条件/目标 | 算法 | 典型时间 |
|---|---|---|
| 无权单源 | BFS | O(V+E) |
| 权值仅 0/1 | 0-1 BFS，双端队列 | O(V+E) |
| 非负权单源 | Dijkstra | 见上文 |
| 可有负权，需检测源点可达负环 | Bellman–Ford | O(VE) |
| DAG 可有负权 | 按拓扑序松弛 | O(V+E) |
| 全源最短路，小型稠密图 | Floyd–Warshall | O(V³)，空间 O(V²) |

Bellman–Ford 做 V−1 轮全边松弛；再一轮仍能改进，则存在源点可达负环。受该负环影响的点没有有限的最短路。参考程序中的 Bellman 函数仅用于非负图对照，**不是含负环检测的完整接口**。

Floyd 的 k 必须在最外层：当前阶段允许中间点来自前 k 个点，转移 `d[i][j]=min(d[i][j],d[i][k]+d[k][j])`，注意不可达判断。

## 4. MST 优化的是整张连接网络

最短路树最小化源点到各点的路径长度；最小生成树最小化连接所有点所用边权之和。两者不同。MST 通常讨论无向连通图，负边权也可处理。

Kruskal：按权重从小到大遍历边；若两端代表元不同，则接纳此边并合并。连通图接纳 V−1 条边；非连通图得到最小生成森林。排序 O(E log E)，并查集操作近似线性。

正确性依靠割性质：把当前一个分量与其余点分开，跨割的最轻边可安全加入某个最优生成树。Prim 则从已选点集合不断加入最轻的跨界边。
