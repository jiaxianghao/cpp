# 09 回溯、枚举与剪枝（第 17–18 周）

先修：递归与树。目标：明确每层决定什么，保证选择和撤销对称。

## 1. 把问题画成决策树

子集：对每个元素决定选/不选。排列：每层决定下一个位置放哪个尚未使用的元素。组合：每层选择下一个元素，索引只向后，避免顺序不同但集合相同的重复结果。

通用过程：到达结束条件就保存答案；否则枚举合法选择，修改 path/used，递归到下一层，再撤销修改。递归调用返回时，父层状态必须与调用前一致。

保存答案应复制当前 path，不能只保留以后还会变动的同一个缓冲区引用。

## 2. 子集与排列的规模不同

n 个互异元素有 2ⁿ 个子集，完整保存总元素量为 O(n·2ⁿ)。n 个互异元素有 n! 个排列，每个长 n，所以输出本身就需要 O(n·n!) 时间与空间；不能要求输出全部结果还做到 O(n²)。

递归栈、used、当前 path 额外为 O(n)，这是**不计输出**的空间。规模很大时先问是否真的需要全部答案。

## 3. 重复元素如何去重

示例对输入排序，对排列中的选择 i，若 `a[i]==a[i-1]` 且前一个相等元素当前未使用，就跳过 i。含义是：同一决策层，相同值只允许最靠前的可用元素作为起点。

对 `[1,1,2]`，两个 1 若都作为第一层选择，会生成相同值序列；但当前路径已经使用第一个 1 时，第二层仍允许使用第二个 1，否则会漏掉 `[1,1,2]`。

所以不能简单写“见到相等就跳过”。子集/组合的常见条件 `i>start && a[i]==a[i-1]` 与排列的 used 条件不同，来源于不同的状态定义。

## 4. 剪枝必须有理由

组合选 k 个：如果“已经选的个数 + 剩余个数 < k”，这条分支无法完成，可以剪枝。

正数求目标和：当前和超过目标后可停止向下选；存在负数时这个剪枝不再安全，后面的负数可能让总和降回来。剪枝只能删除不可能或不优于已有解的分支，不能凭感觉跳过。

记忆化适用于重复的等价子问题；如果答案依赖整个当前路径，仅用递归深度作为缓存键通常不够。
