# 独立练习册

每模块只要求完成 **A 必做题**。B/C 为可选变式，不必挤进每天 30 分钟。建议先写题意、暴力解和边界，再打开模板实现；不要同时打开参考程序与练习文件。

模板的 TODO 是刻意留给你的练习，不是参考程序中的缺陷。每个模板附有检查，初始运行会抛出 TODO 异常。实现后执行 `cmake --build build --target practice_01 && ./build/practice_01`，替换编号即可。可以新增辅助函数和头文件，不要删掉原有检查来让程序通过。

卡住时按顺序：手算小例子 → 写暴力解 → 看 [分层提示](../docs/SOLUTIONS.md)。最后补一条自己的边界检查，口述复杂度。B/C 的参考方向也在答案页。

## 01 前缀和

A：[模板](01_practice.cpp)。输入整数数组和多个合法 `[l,r)` 查询，返回各区间和。`a=[2,-1,3,4]`、查询 `(1,4),(0,0),(0,4)` → `[6,0,8]`。允许空数组和空区间，累计结果用 long long；希望 O(n+q) 时间、O(n+q) 总额外空间（含输出）。

B：差分数组：长度 n 初值全 0，多次把 `[l,r)` 加 delta，最后一次输出全部值。例 n=5，`[1,4)+2,[2,5)-1` → `[0,2,1,1,-1]`。目标 O(n+q)。

C：实现 O(n²) 和 O(n) 最大子数组，生成长度不超过 8、值在 [-3,3] 的小数组对照。约定子数组非空；空输入不在题目定义内。

## 02 数组去重

A：[模板](02_practice.cpp)。输入非递减数组，原地保留每种值一次，返回逻辑长度 k。`[1,1,2,2,3]` → k=3，前 3 项为 `[1,2,3]`；k 之后不要求。目标 O(n) 时间、O(1) 额外空间，不用 set。

B：反转单链表；用三个节点地址验证链接，不仅比较输出值。空链返回 null，单节点链接仍为 null。

C：给定数组，返回每个位置右侧第一个严格更大值的距离，无则 0。`[2,1,2,4,3]` → `[3,1,1,0,0]`。目标 O(n)。

## 03 滑动窗口

A：[模板](03_practice.cpp)。返回字节字符串最长不重复连续子串长度。`abba → 2`，`pwwkew → 3`，空串 → 0。平均 O(n)，不得枚举所有子串。

B：统计和为 k 的连续非空子数组数量，允许负数。`[1,-1,0], k=0 → 3`。先用 O(n²) 暴力，再用前缀和与哈希优化。

C：正整数数组中，求和至少为 target 的最短连续子数组长度；target>0，不存在返回 0。`[2,3,1,2,4,3], target=7 → 2`。解释为什么“正整数”是窗口移动的关键条件。

## 04 二分边界

A：[模板](04_practice.cpp)。在非递减数组中返回第一个严格大于 target 的下标，不存在返回 n。`[1,2,2,4],2 → 3`。目标 O(log n)，要求写出左右区间不变量。

B：返回目标值的出现次数。`[1,2,2,2,4],2 → 3`。不能线性扫描，目标 O(log n)。

C：正整数货物按顺序运输，用不超过 D 天完成，求最小载重。`[1,2,3,4,5],D=3 → 6`。D≥1、数组非空，每天可运输连续多件，单件不能拆。解释判定函数的单调性。

## 05 树高

A：[模板](05_practice.cpp)。返回树高，按节点数计。空树 0、叶子 1、三个节点的单链树 3。目标 O(n)，额外栈 O(h)。

B：不用递归实现中序遍历。根 2、左 1、右 3 → `[1,2,3]`；空树 → `[]`。

C：判断是否为严格 BST，不允许重复键。反例：根 10，左孩子 5，5 的右孩子 12；直接父子比较通过，但整体不是 BST。目标 O(n)，注意整数边界，不通过 key±1 构造越界。

## 06 并查集

A：[模板](06_practice.cpp)。实现初始化、find、unite。unite 在实际合并时返回 true，已同组返回 false。顶点编号合法，实现路径压缩与按大小或秩合并。

B：返回最大的 k 个数，升序输出且保留重复值；0≤k≤n。`[3,1,5,5,2],k=3 → [3,5,5]`。使用大小不超过 k+1 的堆。

C：给定 n 个顶点的无向图边表，返回连通分量数。n=5，边 `(0,1),(1,2),(3,4)` → 2；允许重复边。不要对重复合并重复减计数。

## 07 BFS

A：[模板](07_practice.cpp)。输入非空有向图邻接表和合法源点，返回最少边数距离，不可达 -1。`{{1,2},{3},{3},{},{}}` 从 0 → `[0,1,1,2,-1]`。目标 O(V+E)。

B：增加 parent，恢复从源点到某点的一条最短路径。上例到 3 可为 `[0,1,3]` 或 `[0,2,3]`；到 4 无路径。不要只接受一个固定序列。

C：实现拓扑排序并返回是否有环。`0→1→2` 无环，`0→1→0` 有环。孤立点必须在结果中，空图视为 DAG。

## 08 Kruskal

A：[模板](08_practice.cpp)。无向图顶点 0..n−1，返回最小生成森林总权重和最终分量数。可不连通、可有负权、自环、重边；n=0 合法。三角形边 0–1(1)、1–2(2)、0–2(5) → 权重 3、分量 1。使用排序和并查集，O(E log(E+1)+V+Eα(V))。

B：在 Dijkstra 中记录 parent 并恢复路径。使用讲义图，从 0 到 3 应得到 `[0,2,1,3]`，距离 4；不可达返回空路径并明确状态。

C：实现 Bellman–Ford，返回是否存在源点可达负环。0→1(1)、1→2(−2)、2→1(−2) 从 0 出发应检测到负环；另一个与源点不连通的负环不应误报为“源点可达”。

## 09 子集

A：[模板](09_practice.cpp)。输入互异整数，返回所有子集，不要求输出顺序。`[1,2] → [],[1],[2],[1,2]`；空输入有一个空子集。目标与输出规模相符 O(n·2ⁿ)。

B：输入可含重复值，输出不重复排列。`[1,1,2]` 共 3 个。先排序，并解释同层去重。

C：从 1..n 中选择 k 个不同数，返回组合。n=4,k=2 共 6 个；k=0 有一个空组合，k>n 返回空。添加“剩余数量不足”的安全剪枝。

## 10 合并区间

A：[模板](10_practice.cpp)。输入闭区间 `[l,r]`，l≤r，顺序任意；合并重叠/接触区间，按起点升序返回。`[1,4],[4,5] → [1,5]`，空输入返回空。目标 O(n log n)。

B：半开区间 `[l,r)`、l<r 中选择最多个不重叠区间，接触兼容。`[0,3),[0,1),[1,2),[2,3)` → 3。写出交换论证。

C：构造“区间最短时长优先”和“找零最大面值优先”失败的反例；分别指出正确策略或需要的其他方法。

## 11 最少硬币

A：[模板](11_practice.cpp)。正整数面值硬币无限使用，凑出 amount≥0 所需最少枚数；不可达 −1。`[1,3,4],6 → 2`，`[2],3 → -1`，金额 0 → 0。目标 O(amount×币种数)。

B：0/1 背包先写二维，再改一维；`w=[2],v=[3],C=4 → 3`。保留该例检测错误的正序更新。

C：实现 LCS 长度并画 `ab` 与 `acb` 的表，答案 2。区分最长公共子序列和最长公共子串。

## 12 KMP

A：[模板](12_practice.cpp)。实现首次子串匹配，`ababaca` 中 `abaca` 的下标为 2；空模式返回 0，不存在返回 string::npos。目标 O(n+m)，可与标准库对照，但函数内部不调用 find 代替实现。

B：实现 Fenwick 的 add 和 sum，外部下标 0-based，sum(r) 求 `[0,r)`。`[1,2,3]` 在下标 1 加 4 后，`sum(3)-sum(1)=9`。

C：找所有允许重叠的模式出现位置。`text=aaaa,pattern=aa → [0,1,2]`。本题约定模式非空；匹配完整后应如何更新 j？
