# 《操作系统导论》四周复习包

适合读过 OSTEP、希望重新建立知识框架的人。默认会基本 C 语法和 Linux 命令，每天 45～60 分钟、每周六天学习加一天复盘，四周约 24 小时。全部笔记是重新组织的中文学习材料；书籍原文通过链接阅读。

## 从这里开始

1. 打开 [学习计划](docs/plan.md)，做第 1 天的闭卷摸底。
2. 阅读 [知识地图](docs/01-overview.md)，回忆三条主线。
3. 在本目录运行下面的命令，再按 [实验手册](docs/labs.md) 完成实验 1。

```sh
make
./build/process
make check
```

需要 Linux、C11 编译器、make、Python 3，无第三方 Python 包，也不需要 root。`make check` 会编译并检查实验结果；学习时请先预测输出，再逐个执行。程序仅在 `build/` 中生成测试文件；文件更新实验使用临时目录并自动清理。

## 学习方式

每天用 5 分钟闭卷回忆昨天内容，15 分钟读笔记或原书，25 分钟做实验，5～10 分钟用自己的话写结论。遇到遗忘先写下自己的猜测，不要立刻翻答案。同一主题在 1、3、7 天后各回忆一次。

本包先恢复核心概念，不覆盖整本书。彩票调度、多核调度、完整内存系统、RAID、LFS、分布式文件系统和安全章节留作第二轮。实验是教学模型；调度模拟器并不代表当前 Linux 的实际调度策略。
