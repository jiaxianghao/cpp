## 完成标准与调整方式

自测每题 0～2 分：完全不会 0 分；结论对但原因不清 1 分；能解释并举例 2 分。总分至少 26/32，且进程、内存、并发、持久化各组至少 6/8，视为完成第一轮。未达标时再用三天重做最弱的一组，不必从头重读。

每天只有 20～30 分钟就把一个学习日拆成两天，延长到八周。某一组摸底已得 7～8 分，可以先做实验和自测，通过后跳过该组的细读，保留周复盘。不要用“读过多少页”作为进度指标。
